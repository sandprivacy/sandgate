Five tools. Every wall an agent hits.

Agents stall on everything that needs a human. sandgate turns each wall into one MCP call — with your policy, your tap, and an audit line.

request_approval

“May I pay €300 on this site?” Push to your phone; no answer within the timeout means denied.

ask_human

“What’s the SMS code?” Your phone shows an input field; the answer returns end-to-end encrypted. Real number, no VoIP tricks.

get_totp

The current 6-digit code for a domain. Per-domain policy: auto, approve, or deny. The seed is never exposed.

create_identity

A disposable email inbox so the agent signs up without your real address — sandmail or your own IMAP.

wait_for_verification

Long-polls that inbox and returns the extracted code and links the moment the email lands.

Built like it doesn't trust anyone

Including us. The relay that reaches your phone forwards sealed blobs it can neither read nor forge — and there's a test in the repo that proves it.

Zero disclosure

The LLM only ever sees derived, short-lived values — a 6-digit code, a yes/no. Never seeds, tokens or passwords.

Deny by default

Unknown domains refuse. Unanswered approvals refuse. A dropped connection refuses.

Face ID, verified

Optional: approvals carry a WebAuthn assertion from your phone’s secure enclave, checked against the enrolled key. Not a tap the page claims happened.

End-to-end encrypted

The pairing secret travels once, in a URL fragment. HKDF → AES-256-GCM, request id bound into the AAD.

Self-hosted

Vault, policies and audit live on your machine. Run your own relay, or use ours — it's blind either way.
